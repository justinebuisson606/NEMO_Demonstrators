# User Guide

This section describes how the demonstrators are organised.

| Folder | Content |
|---|---|
| `docs/` | Source of this website (Markdown) |
| `*.ipynb` (root) | Demonstrator and annex notebooks, copied to `docs/notebooks/` at build time |
| *(your experiment folders)* | NEMO namelists and run scripts |

Each demonstrator should provide: a short description, the namelists used, the
expected outputs, and a notebook reproducing the figures.
