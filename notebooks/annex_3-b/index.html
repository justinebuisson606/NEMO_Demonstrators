    Annex 3-B - Overshootings caused by bi-laplacian diffusion¶

    Aim of Tutorial¶

    The aim of this tutorial is to visualize the positive or non positive property of the tracer diffusion schemes.

    Running the simulation¶

    To run the simulation we need to run a traadvOFF+LAP simulation and a traadvOFF+BILAP simulation in the case of the saltblock. You can do so yourself under the experience names cn_exp = CANAL_saltblock_lap_traadvOFF and CANAL_saltblock_blp_traadvOFF or you can execute the cell below.
